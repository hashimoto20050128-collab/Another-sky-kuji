========================================================
 Another Sky ｜ Firestore セキュリティルール（これだけでOK）
========================================================

貼り付け方：
  Firebaseコンソール → Firestore Database →「ルール」タブを開く
  → 表示されている中身をすべて消す
  → 下の「★ここから★」〜「★ここまで★」の“間”をコピーして貼り付ける
  →「公開」を押す

くじ（抽選）と通知（呼び出し・受け取り）の両方が、これ1つで有効になります。
他に貼るものはありません。


★ここから★────────────────────────────────────────────
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // くじ（抽選）: 読み書きはログインした店員のみ。
    // 当たり金額の書き換えや使用済みの取り消しはできない。
    match /as_kuji_tickets/{code} {
      allow read: if request.auth != null;
      allow create: if request.auth != null
                    && request.resource.data.keys().hasOnly(['prize','used','usedAt','day','seq'])
                    && request.resource.data.used == false;
      allow update: if request.auth != null
                    && resource.data.used == false
                    && request.resource.data.used == true
                    && request.resource.data.prize == resource.data.prize;
      allow delete: if request.auth != null;
    }

    // 通知（呼び出し・受け取り）: 状態の閲覧は誰でも可、
    // 作成・呼び出し・受け渡し・削除はログインした店員のみ。
    match /as_orders/{code} {
      allow read:  if true;
      allow write: if request.auth != null;
    }

  }
}
★ここまで★────────────────────────────────────────────


--------------------------------------------------------
 このルールでできること（参考・貼り付け不要）
--------------------------------------------------------
・くじ：店員がログインして券の発行・抽選・集計・削除ができる。
        設定（apiKey等）が外部に漏れても、認証情報が無ければ読めず書けない。
・通知：お客さんは自分の受け取り状況を見られる（読み取りのみ）。
        注文が一覧に載るのは、店員が抽選でQRを読み取ったときだけ。
        呼び出し・受け渡し・削除は店員のみ。


--------------------------------------------------------
 事前に1回だけ必要な設定（ルールとは別）
--------------------------------------------------------
1) Authentication →「Sign-in method」→「メール/パスワード」を有効化
2) Authentication →「Users」→「ユーザーを追加」で店員アカウントを作成
   （このメール・パスワードで、店員用の各ページにログインします）


--------------------------------------------------------
 日をまたいで使う場合
--------------------------------------------------------
・呼び出し一覧をリセットしたいときは、Firestore の「as_orders」
  コレクションだけを削除（コレクションを削除）してください。
・「as_kuji_tickets」は消さないこと（券・使用済みの記録が消えます）。
  ルールの貼り替えは不要です（一度公開すればそのままで大丈夫）。
